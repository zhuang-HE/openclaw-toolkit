## 📊 数据库结构

### 1. 消费级无人机数据库（17 个字段）

**文件：** `drone_data/消费级无人机数据库.csv`

| 字段类别 | 字段数 | 字段名称 |
|---------|--------|---------|
| 基础信息 | 5 | 品牌、型号、价格 (元)、主要用途、使用者类型 |
| 销量数据 | 4 | 2021-2024 年销量 |
| 事故数据 | 5 | 2021-2024 事故数、事故总数、人员伤亡数 |
| 损失金额 | 2 | 机损金额 (元)、物损金额 (元) |
| 验证信息 | 1 | 数据来源、验证状态 |

**机型数量：** 17 款（大疆、极飞、纵横等）

---

### 2. 货运无人机数据库（52 个字段）

**文件：** `drone_data/货运无人机数据库_完整版.csv`

#### 基础字段（17 个，与消费级一致）
- 品牌、型号、价格 (元)、主要用途、使用者类型
- 2021-2024 年销量
- 2021-2024 事故数、事故总数、人员伤亡数
- 机损金额 (元)、物损金额 (元)

#### 运输数据（4 个）
- 2021-2024 年运输架次

#### 货物损失数据（9 个）
- 2021-2024 年货物损失事故数
- 货物损失事故总数
- 2021-2024 年货物损失价值 (元)
- 货物损失总价值 (元)、平均货物损失 (元/起)、货物损失率 (‰)

#### 性能规格数据（15 个）⭐ NEW
- **尺寸：** 机身长度 (m)、机身宽度 (m)、机身高度 (m)、轴距 (m)
- **重量载荷：** 最大起飞重量 (kg)、有效载荷 (kg)、货箱容积 (L)
- **飞行性能：** 最大平飞速度 (km/h)、巡航速度 (km/h)、最大航程 (km)、续航时间 (min)、最大飞行高度 (m)
- **环境适应性：** 工作温度范围、抗风等级、防护等级

#### 保险费率（3 个）
- 保险费率_机身‰、保险费率_三者‰、保险费率_货物‰
- 综合费率%、年保费 (元)

#### 验证信息（2 个）
- 风险等级、风险系数、数据来源、验证状态

**机型数量：** 8 款（大疆 FlyCart 30、顺丰方舟、美团 V21 等）

### 数据更新流程

```
1. 备份旧数据 → drone_data/货运无人机数据库_backup_YYYYMMDD_HHMMSS.csv
2. 收集新数据 → 制造商官网、行业报告、运营数据
3. 验证数据 → 交叉验证、合理性检查
4. 更新数据库 → 写入 CSV
5. 生成报告 → reports/drone/月度报告
6. 发送通知 → 飞书 Webhook
```

## 🔍 数据验证

### 验证规则

| 验证类型 | 检查项 | 通过标准 |
|---------|--------|---------|
| 完整性 | 必填字段 | 所有必填字段有值 |
| 一致性 | 事故总数 | = 各年事故数之和 |
| 合理性 | 损失率 | < 机身事故率 |
| 交叉验证 | 货物损失 | ≤ 总事故数 |
| 计算验证 | 平均损失 | = 总损失/事故数 |

### 验证脚本

```bash

python3 /home/admin/.openclaw/workspace/scripts/validate_cargo_drone_data.py
```

### 常见问题

**Q: 如何添加新机型？**
A: 在对应 CSV 文件中添加一行，确保所有字段都有值。

**Q: 如何修改字段？**
A: 修改生成脚本中的 `fieldnames` 列表，然后重新生成 CSV。

**Q: 数据收集失败怎么办？**
A: 检查日志文件 `logs/cron_*.log`，根据错误信息修复。
