# 🤖 机器人数据收集自动化系统（增强版）

## 📋 系统概述

本系统实现机器人数据库的自动化数据收集、更新和日报推送，具备高级数据分析功能。

### 核心功能

- ✅ **定时收集**：每天 9:00 自动执行数据收集
- ✅ **日报推送**：每天 20:00 生成并推送日报
- ✅ **Token 控制**：每日消耗不超过 100 万 token
- ✅ **多渠道收集**：官方渠道 + 行业平台 + 公开数据
- ✅ **事故案例库**：累积存储事故案例，支持查询分析
- ✅ **价格趋势分析**：跟踪机器人价格变化，生成趋势报告
- ✅ **重大事件告警**：伤亡/高损失/价格暴跌自动告警
- ✅ **行业网站爬取**：支持高工机器人网等网站爬取（可扩展）
- ✅ **错误处理**：完善的日志和异常处理机制

## ⚙️ 配置说明

### Token 控制

在 `机器人数据收集自动化_增强版.py` 中配置：

```python
DAILY_TOKEN_LIMIT: int = 1_000_000  # 每日 100 万 token
TOKEN_COST_PER_REQUEST: int = 100   # 估算每次请求 token 消耗
```

### 收集时间

```python
COLLECTION_TIME: str = "09:00"  # 收集时间
REPORT_TIME: str = "20:00"      # 报告时间
```

### 飞书推送配置

```python
WEBHOOK_URL_MONTHLY = "https://open.feishu.cn/open-apis/bot/v2/hook/5128a9a6-8f58-407a-9cbe-5f816713d289"  # 日报
WEBHOOK_URL_ALERT = "https://open.feishu.cn/open-apis/bot/v2/hook/5128a9a6-8f58-407a-9cbe-5f816713d289"  # 告警
```

### 告警阈值配置

```python
ALERT_THRESHOLDS = {
    "death_count": 1,           # 死亡人数达到即告警
    "serious_accident_count": 3, # 严重事故数达到即告警
    "loss_amount": 200,         # 损失金额超过 200 万即告警（万元）
    "price_drop_threshold": -20, # 价格下降超过 20% 告警
}
```

## 📊 数据收集流程

```
1. 爬取行业网站数据（高工机器人、中国机器人网）
   ↓
2. 收集机器人销量和价格数据
   ↓
3. 收集保险公司事故数据
   ↓
4. 收集事故案例详情
   ↓
5. 保存价格历史记录
   ↓
6. 保存事故案例到数据库
   ↓
7. 分析价格趋势
   ↓
8. 发送重大事件告警
   ↓
9. 生成日报
   ↓
10. 推送日报到飞书
   ↓
11. 记录执行日志
```

## 📝 日报内容

每日生成的报告包含：

- **收集概览**：数据库产品总数、平均价格、事故案例数
- **完成工作**：今日执行的任务列表
- **价格趋势分析**：各机型环比变化（上升/下降/稳定）
- **事故案例**：今日事故案例详情 + 数据库累计
- **告警统计**：重大事件告警数量
- **明日计划**：下一步工作安排

## 🔧 高级功能说明

### 事故案例数据库

系统自动累积事故案例到 `robot_data/机器人事故案例库.csv`：

- **自动去重**：基于案例 ID 避免重复入库
- **统一字段**：标准化字段格式（品牌/型号/事故类型/地点/损失/伤亡/原因）
- **累计统计**：日报中显示累计案例数
- **查询分析**：可用于后续数据分析和趋势研究

**字段说明**：
```csv
案例 ID,入库时间，日期，品牌，型号，事故类型，地点，损失，伤亡，原因，来源
ROBOT-202603-20260310-000,2026-03-30 10:43:32,2026-03-10，发那科 FANUC,M-20iD/25，机械故障，广东省东莞市，机损 12 万元 + 停产损失 30 万元，1 人轻伤，减速机磨损，保险公司理赔报告
```

### 价格趋势分析

系统自动跟踪各机型价格变化：

- **历史记录**：每次收集保存到 `产品价格历史趋势.csv`
- **趋势计算**：环比变化百分比（上升/下降/稳定）
- **可视化**：日报中展示各机型价格趋势表
- **决策支持**：帮助评估市场价格走势

**字段说明**：
```csv
收集时间，月份，品牌，型号，价格，环比
2026-03-30 10:43:32,2026-03，发那科 FANUC,M-20iD/25,180000,+2%
```

### 重大事件告警

自动检测并推送重大安全/市场事件：

**告警触发条件**（可配置）：
- 伤亡事故（死亡/重伤）≥ 1 例
- 损失金额 ≥ 200 万元
- 价格下降 ≥ 20%

**告警方式**：
- 飞书即时消息推送
- 包含事件详情和损失/价格信息
- 可与日报推送使用不同 Webhook

### 行业网站爬取

支持从行业网站爬取真实数据：

- **爬取目标**：高工机器人网、中国机器人网等
- **自动降级**：爬取失败时使用模拟数据
- **可扩展**：可添加更多数据源
