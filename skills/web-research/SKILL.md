# Web Research Skill

## Task
深度网络研究和信息整理，提供结构化研究报告。

## Workflow

### Phase 1: 理解需求
1. 明确研究主题和核心问题
2. 确定需要的信息类型（数据/观点/教程/对比等）
3. 识别关键搜索词和排除词

### Phase 2: 执行搜索
1. 使用 `web_search` 进行多角度搜索（至少 3 个不同查询）
2. 覆盖主题的不同维度（官方/社区/媒体）
3. 记录搜索来源便于追溯

### Phase 3: 获取内容
1. 用 `web_fetch` 获取高相关性页面内容
2. 提取核心数据和引用
3. 交叉验证关键信息

### Phase 4: 整理报告
1. 综合多来源信息
2. 标注信息来源和置信度
3. 生成结构化输出

## Output Format

```markdown
# [研究主题] 研究报告

## 核心摘要
[200-300 字核心发现]

## 关键发现
1. [发现 1] - 来源：[链接]
2. [发现 2] - 来源：[链接]
3. [发现 3] - 来源：[链接]

## 详细分析
[分章节详细论述]

## 数据来源
| 来源 | 类型 | 可信度 | 链接 |
|------|------|--------|------|
| ...  | ...  | ...    | ...  |

## 时效性说明
- 信息收集时间：YYYY-MM-DD
- 数据有效期：[说明]

## 置信度评估
- 整体置信度：高/中/低
- 评估依据：[说明]
```

## Rules

1. **多源验证**: 关键信息至少 3 个独立来源验证
2. **优先权威**: 优先官方文档、学术论文、权威媒体
3. **标注时效**: 明确标注信息收集时间和有效期
4. **引用链接**: 所有数据必须有可追溯链接
5. **区分事实与观点**: 明确区分客观事实和主观观点
6. **中文输出**: 除非特别要求，默认中文输出

## Tools Used

- `web_search` - 网络搜索（通用，替代 searxng）
- `web_fetch` - 网页内容提取
- `write_to_file` - 保存研究报告

## Examples

### Example 1: 技术调研
```
用户：调研一下 2026 年最新的 AI Agent 框架

执行：
1. 搜索 "AI Agent framework 2026"
2. 搜索 "best agent orchestration tools 2025 2026"
3. 获取 GitHub 热门项目页面
4. 整理对比报告
```

### Example 2: 竞品分析
```
用户：分析一下主要的 AI 助手框架竞品

执行：
1. 搜索各框架官方文档
2. 获取功能对比信息
3. 整理优劣势分析
4. 输出结构化报告
```

### Example 3: 政策/法规调研
```
用户：查一下无人机保险的监管要求

执行：
1. 搜索最新无人机管理条例
2. 查找保险监管政策文件
3. 整理合规要求报告
```

## Notes

- 如遇付费墙，寻找替代来源或摘要
- 敏感话题需多方验证，避免单一来源偏见
- 技术文档优先查看官方最新版本
- 微信公众号文章适合中文信息密集场景（可用 wechat-article-search skill）
