## 3. 质量评分系统

### 评分维度详解

| 维度 | 权重 | 评估标准 | 打分区间 |
|------|------|---------|----------|
| **目标达成** | 30% | 需求完成度、输出可用性 | 1-5 |
| **执行效率** | 25% | 步骤数、Token、时间 | 1-5 |
| **工具选择** | 15% | 场景匹配度、最优性 | 1-5 |
| **用户理解** | 15% | 需求偏差、沟通质量 | 1-5 |
| **知识复用** | 15% | 踩坑积累、Skill 复用 | 1-5 |

### 综合评分公式

```
综合分 = (目标达成×0.30 + 执行效率×0.25 + 工具选择×0.15 + 用户理解×0.15 + 知识复用×0.15)
```

### 评分输出示例

```markdown
## 质量评分报告

### 各维度得分

| 维度 | 权重 | 得分 | 加权分 |
|------|------|------|--------|
| 目标达成 | 30% | 4.5 | 1.35 |
| 执行效率 | 25% | 4.0 | 1.00 |
| 工具选择 | 15% | 5.0 | 0.75 |
| 用户理解 | 15% | 4.5 | 0.68 |
| 知识复用 | 15% | 3.5 | 0.53 |
| **综合评分** | 100% | — | **4.31/5.0** |

### 趋势分析（与上次对比）

| 维度 | 上次 | 本次 | 趋势 |
|------|------|------|------|
| 目标达成 | 4.0 | 4.5 | ↑ |
| 执行效率 | 3.5 | 4.0 | ↑ |
| 综合评分 | 3.8 | 4.31 | ↑ |

### 改进建议
1. 知识复用维度偏低，可封装重复操作为 Skill
2. 执行效率持续提升，保持
```

## 4. 自动触发决策树

```
任务完成？
    │
    ├── 是 → 重试次数 ≥ 2？
    │           │
    │           ├── 是 → 记录踩坑经验
    │           │
    │           └── 否 → 调用次数 ≥ 5？
    │                       │
    │                       ├── 是 → 静默自检
    │                       │
    │                       └── 否 → 输出完成报告
    │
    └── 否 → 用户有负面反馈？
                │
                ├── 是 → D2 专项反思
                │
                └── 否 → 继续执行
```

### 触发阈值汇总

| 触发条件 | 阈值 | 执行动作 |
|---------|------|---------|
| 同一错误重试 | ≥ 2 次 | 追加踩坑经验 |
| 复杂任务完成 | ≥ 5 次调用 | 静默自检 |
| 用户负面反馈 | 任何 | D2 专项反思 |
| 发现新偏好 | 任何 | 立即更新 MEMORY |
| 任务全部完成 | — | 完整反思 + 评分 |
| 可复用模式 | ≥ 3 步 | Skill 候选 |

## 5. 置信度晋升规则

### 晋升条件

| 优先级 | 当前置信度 | 晋升条件 |
|--------|-----------|---------|
| P3 → P2 | [0.5] → [0.7] | 同一内容被提及 ≥ 2 次 |
| P2 → P1 | [0.7] → [0.7] | 用户明确强调 |
| P1 → P0 | [0.7] → [0.9] | 用户明确说"记住" |

### 降级条件

| 优先级 | 降级条件 |
|--------|---------|
| P0 → P1 | 3 个会话周期无验证 |
| P1 → P2 | 2 个会话周期无验证 |
| P2 → P3 | 与新 P0/P1 冲突 |

### 冲突处理

```
规则 1: P0 优先（P0 > P1 > P2 > P3 > P4）
规则 2: 同级冲突 → 保留最新
规则 3: 跨级冲突 → 保留高优先级 + 记录冲突
```

## 7. Escalation 处理指南

### 快速决策表

| 触发条件 | 状态 | 第一反应 |
|---------|------|---------|
| Graphify 安装失败 | BLOCKED | pip install 命令 |
| 代码库过大 | BLOCKED | 缩小范围 |
| 可疑代码 | BLOCKED | 报告 + 建议 code-review |
| 3次失败 | BLOCKED | 建议手动 |
| 敏感代码 | BLOCKED | 跳过分析 |

### Escalation 格式示例

```markdown
STATUS: BLOCKED
REASON: Graphify 安装失败，tree-sitter 依赖冲突
TOOL: Graphify
ATTEMPTED:
  1. python -m graphify ./project
  2. pip install graphifyy
  3. pip install --upgrade graphifyy
RECOMMENDATION: 请运行 `pip install --force-reinstall tree-sitter`
USER_ACTION: 是否强制重新安装依赖？
```
