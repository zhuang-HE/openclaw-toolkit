## 🚀 快速配置（3 步）

### 步骤 1: 获取 Token

**访问**: https://dashboard.ngrok.com/get-started/your-authtoken

1. 如果没有账号，先注册（免费）
2. 登录后复制你的 Auth Token
3. Token 格式类似：`2aBcDeFgHiJkLmNoPqRsTuVwXyZ123456789`

### 步骤 2: 配置 Token

在终端运行：
```bash
ngrok config add-authtoken 你的_TOKEN_在这里
```

**示例**:
```bash
ngrok config add-authtoken 2aBcDeFgHiJkLmNoPqRsTuVwXyZ123456789
```

### 步骤 3: 运行测试

```bash

```

- ✅ 检查 ngrok 安装
