## 📁 创建的文件

### 1. systemd 服务文件

**路径**: `/etc/systemd/system/robot-api.service`

```ini
[Unit]
Description=Robot Database API Server
After=network.target

[Service]
Type=simple
User=admin
WorkingDirectory=/home/admin/.openclaw/workspace/api
ExecStart=/usr/bin/python3 /home/admin/.openclaw/workspace/api/robot_api_server.py
Restart=always
RestartSec=10
StandardOutput=append:/home/admin/.openclaw/workspace/logs/api.log
StandardError=append:/home/admin/.openclaw/workspace/logs/api_error.log

Environment="PYTHONUNBUFFERED=1"
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

### API Keys

| Key | 用途 | 限流 |
|-----|------|------|
| `sk_robot_demo_key_123456` | 测试/演示 | 60 次/分钟 |
| `sk_robot_ai_agent_001` | AI 智能体 | 100 次/分钟 |

### 对接示例

```python
import requests

API_KEY = "sk_robot_ai_agent_001"
BASE_URL = "http://localhost:8000"

# 搜索机器人
response = requests.get(
    f"{BASE_URL}/api/robots/search",
    headers={"X-API-Key": API_KEY},
    params={"q": "人形", "price_max": 300000}
)

if response.json()['success']:
    robots = response.json()['data']['data']
    for robot in robots:
        print(f"型号：{robot['型号']}, 价格：{robot['价格 (元)']}")
```
